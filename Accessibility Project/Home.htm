Digital Accessibility

Accessibility / Flare Project

The purpose of our Accessibility/Flare project for English 381 is to provide information on technological accessibility features and practices while learning new technologies and systems ourselves. This project centers around learning and understanding the practice and principles of web accessibility. My project involves the use of closed captioning, which I worked to create modules about with a small group in my class.

Web accessibility, in short, is the quality of a website, technical feature, or media modality being usable and accommodating to any person of any level of capability.

About Me

Tools and Concepts Used

Our first program that we are learning is MadCap Flare. This is a Help Authoring Tool (HAT). In using this tool, we are practicing the rules of web accessibility, which have a lot to do with the core principles as described by the World Wide Web Consortium (W3C). These principles are commonly summarized as POUR: Perceivable, Operable, Understandable, and Robust.

  • P: “Perceivable” means that users must be able to sense the content through at least one of their available senses. For example: If someone cannot see, text alternatives (like alt text for images) allow screen readers to convey meaning.
  • O: “Operable” means that interface components and navigation must be usable through different input methods. Not everyone uses a mouse. Some people rely on a keyboard, voice control, switch devices, or other assistive technologies.
  • U: “Understandable” refers both to the clarity of information and the predictability of the interface. If you are a writer or information designer, this principle speaks directly to your craft. Clear headings, plain language, consistent terminology, and logical structure all support comprehension.
  • R: “Robust means it should work reliably with a wide range of current and future technologies, including assistive technologies like screen readers.

Keeping these principles in mind, our class created modules relating to different forms of accessible technology features to include in our websites. Each group in our class developed sets of modules that are organized into each of the tabs on the navigation menu of this website. My group developed the modules on Closed Captions, and I specifically wrote the definition and significance of close captions pages. This project was meant to introduce MadCap Flare to our class, and help us all gain experience in using it. With lots of trials and tribulations, but all love, this website will be turned in as my final project in my PWTC courses before I graduate.
